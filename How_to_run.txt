How to run it on your other system:
Copy the folder: Copy the entire d:\FYP_AI_PROJECT folder to your target machine.
Install requirements: Open a terminal in that folder and run:
bash
pip install -r requirements.txt
Train the Model: Run the main pipeline (which does data generation, training, and evaluation):
bash
python main.py
For better quality with more data and longer training, you can run:
bash
python main.py --augment-total 2500 --epochs 160

If you only want to regenerate a bigger dataset first:
bash
python augment_data.py --total 3000
Launch the Web Interface:
bash
python app.py
Then open your web browser and go to http://localhost:5000.
Please take a look at the generated files, and let me know if you need any adjustments or if you have any questions for your viva preparation!
